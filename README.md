# 🛡️ Анти ИИ Штрих-код

**Бесплатный офлайн-сканер для проверки подлинности товаров**  
Распознаёт EAN-13, DataMatrix (Честный ЗНАК) и защищает от ИИ-подделок.

[![Vercel](https://img.shields.io/badge/Демо-Anti--AI--Barcode-black?logo=vercel)](https://anti-ai-barcode.vercel.app/)
[![Лицензия](https://img.shields.io/badge/Лицензия-MIT-green.svg)](LICENSE)

---

## 📱 О проекте

«Анти ИИ Штрих-код» — это веб-приложение, которое позволяет мгновенно проверять подлинность товаров по штрих-коду или DataMatrix-маркировке (включая систему «Честный ЗНАК»).  
Приложение работает **офлайн** (кроме первого сканирования камеры), не собирает данные и полностью бесплатно.

**Главная идея:** дать каждому покупателю простой и быстрый инструмент для выявления подделок, включая те, что созданы с помощью искусственного интеллекта (искажённые геометрии, нечитаемые микро-элементы и т.д.).

---

## ✨ Особенности

- 🔍 **Сканирование** EAN-13, EAN-8, ITF-14 и DataMatrix (Честный ЗНАК)
- 🧠 **Анализ качества печати** — выявляет аномалии, похожие на ИИ-манипуляции
- 🗣️ **Голосовое озвучивание** результатов (русский язык, мужской голос)
- 📜 **История проверок** (сохраняется в `localStorage`)
- 📤 **Экспорт истории** в JSON
- 🌐 **Полностью офлайн** после загрузки (кроме камеры)
- 🎨 **Адаптивный интерфейс** в стиле мобильного приложения (9:16)
- 🔄 **Смена камеры** (передняя/задняя)
- ⌨️ **Ручной ввод кода** (13 цифр)

Запустите локальный сервер (например, через VS Code Live Server или Python):

bash
python3 -m http.server 8000
Откройте в браузере: http://localhost:8000

Разрешите доступ к камере при запросе.

📖 Как это работает
Сканирование — камера считывает штрих-код через библиотеку ZXing.

Валидация — проверяет контрольную сумму EAN-13, EAN-8, ITF-14.

Для DataMatrix — ищет крипто-хвосты (GS1-строки 91/92 / «криптохвост»).

Анализ ИИ-признаков — эмулирует проверку контрастности/чёткости границ.

Вывод результата — показывает уровень доверия (0–100%) и справочную информацию.

Голос — озвучивает вердикт (включён по умолчанию).
